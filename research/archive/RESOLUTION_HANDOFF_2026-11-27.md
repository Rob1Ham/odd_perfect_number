# Odd perfect number resolution handoff

Read this first when picking up the component-index, sixth-power, Euler-index, or Tóth work. The target is `OddPerfect.existsOddPerfect`, defined as `∃ N : ℕ, Odd N ∧ Nat.Perfect N`. The project has proved restrictions on every candidate and eliminated specific branches. The general existence question remains unresolved by these imports.

### Why the one-sixth strategy changes on the sixth-power-free branch

On this branch write $Q$ for the number of exponent-four primes and $S$ for the number of exponent-two primes. The Euler exponent is one, $Q\ge147$, and $\omega=1+S+Q$. Quartic divisor sums send their prime factors into the residue class one modulo five. A non-Euler target there cannot have exponent four because that exponent would force 5. The resulting valuation budgets give
$$5Q\le 6+8C,\qquad 3S\le 3+6Q.$$
In particular $5\omega\le24C+28$, $C\ge92$, and $6C>\omega$. Taking the contrapositive, any candidate with fewer than 92 such primes or with $6C\le\omega$ admits a six-factor index drop. The latter statement is `exists_componentIndex_cardFactors_add_six_le_of_few_square_sources`. This is a restriction on any hypothetical sixth-power-free candidate. A proof of $6C\le\omega$ for every sixth-power-free candidate would therefore exclude the entire branch. The earlier 1231 implication with $C=0$ has no surviving candidate to which it applies. The slope theorem with a one-sixth allowance still applies on other branches. A next proof must account for many shared targets. [Density theorem](../../OddPerfect/SixthPowerFreeEuler.lean) · [Quartic incidence bounds](../../OddPerfect/ZelinskyFullSlope.lean)
